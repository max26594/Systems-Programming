# Вступ до ОС Linux та скриптів Bash

## 🐧 Що таке ОС GNU/Linux?
**Linux** — це сімейство вільно поширюваних операційних систем з відкритим вихідним кодом (Open Source), побудованих на базі ядра Linux. 
Правильніше називати цю систему **GNU/Linux**, оскільки сама по собі Linux — це лише ядро (взаємодіє з обладнанням), а більшість базових утиліт та програм для роботи користувача були створені в рамках проекту GNU.

**Ключові особливості:**
- Повна безкоштовність та відкритість коду.
- Високий рівень безпеки та стабільності.
- Широке використання на серверах, суперкомп'ютерах, смартфонах (Android) та вбудованих системах.

---

## 💿 Найбільш популярні дистрибутиви
Дистрибутив — це операційна система на базі ядра Linux, яка включає набір програмного забезпечення.
1. **Ubuntu** — найпопулярніший дистрибутив для початківців, має велику спільноту та зручний графічний інтерфейс.
2. **Debian** — один з найстаріших дистрибутивів, відомий своєю неймовірною стабільністю. (Ubuntu базується саме на ньому).
3. **Linux Mint** — дуже зручний для переходу з Windows, має схожий інтерфейс.
4. **Fedora** — містить найновіші версії програмного забезпечення, підтримується компанією Red Hat.
5. **Arch Linux** — дистрибутив для просунутих користувачів, збирається з нуля "під себе".

## 💻 Базові команди Linux CLI (Command Line Interface)
Командний рядок — основний інструмент адміністратора Linux. Ось базові команди:

| Команда | Опис | Приклад використання |
|---------|------|----------------------|
| `pwd` | Показує повний шлях до поточної директорії | `pwd` |
| `echo` | Виводить текст або значення змінної на екран | `echo "Hello, Linux"` |
| `ls` | Виводить список файлів і папок у директорії | `ls -la` (детальний список) |
| `cd` | Змінює поточну директорію (перехід по папках) | `cd /var/www` |
| `touch` | Створює новий порожній файл або оновлює час його зміни | `touch index.html` |
| `mkdir` | Створює нову директорію (папку) | `mkdir my_project` |
| `cp` | Копіює файли або директорії | `cp file.txt copy.txt` |
| `mv` | Переміщує або перейменовує файли | `mv old.txt new.txt` |
| `rm` | Видаляє файли або директорії | `rm -r my_folder` |
| `history` | Показує історію раніше введених команд | `history` |

## 🔐 BASH-cкрипт: Імітація авторизації
Нижче наведено приклад простого Bash-скрипта, який запитує логін та пароль у користувача.

```bash
#!/bin/bash

# Очищуємо екран для кращого вигляду
clear

echo "==================================="
echo "    Система авторизації v1.0       "
echo "==================================="

# Запитуємо логін
echo -n "Введіть логін: "
read username

# Запитуємо пароль (прапорець -s приховує введення)
echo -n "Введіть пароль: "
read -s password
echo "" # Перехід на новий рядок після введення пароля

echo "==================================="
echo "Обробка даних..."
sleep 2 # Пауза на 2 секунди для імітації завантаження

# Перевірка введених даних (логін: admin, пароль: 12345)
if [ "$username" == "admin" ] && [ "$password" == "12345" ]; then
    echo "✅ Доступ дозволено! Вітаємо, $username."
else
    echo "❌ Помилка: Невірний логін або пароль!"
fi
echo "==================================="
```
